## 🚀 Featured Projects

### 🛡 [telegram-antispam-shield](https://github.com/privatekey7/telegram-antispam-shield) — ML anti-spam bot (Rust + Python)
Trained spam classifier (97% accuracy, 0.994 ROC-AUC, ~1% false positives) embedded into a Rust `teloxide` bot. Modular architecture, ADR docs, CI with `cargo audit`, Docker, one-click Railway deploy.

### 🤖 [FreeClaw](https://github.com/privatekey7/FreeClaw) — One-command Telegram AI agent deploy
Spins up a Telegram AI agent (OpenClaw + Qwen via OpenRouter) on a fresh VPS with a single command. Proxy-per-key rotation, real-time rate-limit monitoring, automatic recovery.

### 🎙 [Vox](https://github.com/privatekey7/Vox) — Offline voice-to-text for Windows
Hold right Ctrl, speak, release — text appears at the cursor, in any app. 5 ML models to choose from (Whisper / GigaAM v3 / Vosk / Parakeet / SenseVoice). Fully local inference, no cloud, no telemetry.

### 📊 [DeBank-Pro](https://github.com/privatekey7/DeBank-Pro) — DeFi portfolio analytics
Tracks DeFi assets across 90 networks and 600+ protocols. Proxy rotation, Excel/CSV/JSON export, filters by chain/token/NFT.
